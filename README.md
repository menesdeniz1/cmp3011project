# Face-mask detection coursework — source archive

Historical coursework comparing YOLO and SSD experiments. This older project overlaps with the separate face-mask-detection repository and is retained as an **archived source reference**, not a flagship or maintained application.

The public edition contains Python/notebook source only. The original report, video, trained weights, plots and embedded notebook outputs were removed from reachable history during September 2026 publication cleanup and retained in the owner's local backup. Their redistribution rights and personal content were not certified.

Bring your own authorized dataset and trusted compatible model. Notebook paths and training setup are historical and need adaptation. Install `ultralytics` and `opencv-python` in an isolated environment, set `MASK_MODEL_PATH` to a local YOLO checkpoint and run `python webcamtest.py` only when camera access is intended. No model is downloaded automatically by this entry point.

No accuracy, live-camera, training-reproduction or production-readiness claim is made. Do not infer new model results from old source. Team/commit authorship is preserved; removed material is not silently represented as newly authored work.
